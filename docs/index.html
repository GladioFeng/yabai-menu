A closer look

Know where you are.
Get where you need to go.

Space labels, app icons, and window state share one compact line. Choose how much of your workspace to show.

01

Each display has its own context

Show all displays or just the current one. Distinguish focused, visible, and inactive Spaces, with independent current-Space markers.

02

Go straight to a Space or window

Click a label to switch Spaces or an app icon to focus a window. Use the context menu to manage Spaces, open settings, or quit.

03

See the window state

Show float, stack, or bsp layout, sticky state, and stack position. Add the focused app and window title with the optional Process section.

04

Set the spacing and color

Adjust icons, fonts, backgrounds, and dividers. Use System, Mint, Sky, Catppuccin, or Tokyo Night colors, then customize individual roles.

  1. 1

    Have yabai running

    Follow the yabai setup guide. Yabai Menu uses your existing installation and does not change its configuration files.

  2. 2

    Unzip and move to Applications

    Quit an older copy first, then move Yabai Menu.app to /Applications. To check the download, put the ZIP and checksum in one folder and run:

    shasum -a 256 -c Yabai-Menu-1.0.0-universal.zip.sha256
  3. 3

    Review the macOS opening prompt

    This build uses ad-hoc signing and is not notarized by Apple. If macOS blocks it and you trust the download, follow Apple’s instructions for opening an unverified app.

  4. 4

    Enable native window updates

    In Settings → Connection, choose Enable Native Window Updates…. Allow Yabai Menu in macOS Accessibility settings, then click Check Connection.

Compatibility & validation

Built for macOS 13 and later; macOS 13 runtime verification is pending. Local running records cover Intel macOS 14.8.5 and Apple Silicon macOS 15.7.9. Build 29 CI passed noninteractive tests and universal builds on both architectures. Build 31 updates the app icon only. Physical interaction and display-lifecycle checks remain incomplete.

A few details

Before you settle in.

For configuration, refresh hooks, and diagnostics, see the full README.

Where are Settings in floating mode?

Right-click the bar and choose Settings. Docked and floating bars hide the extra menu-bar entry while they are available. A recovery entry returns when no standalone bar can be shown.

Which app needs Accessibility permission?

Yabai Menu itself needs permission for native window movement and title updates. Enable the copy in /Applications/Yabai Menu.app, then use Check Connection. Copy Diagnostics reports Accessibility and Native window subscriptions so you can check their state.

Will every external yabai command refresh the bar?

Some layout, float, sticky, and window-transfer commands need a refresh notification. Add the documented refresh hook to the relevant script, or use Refresh in the menu.

Can I build it from source?

Yes. Clone the repository and run sh build.sh with a full Xcode installation. The build produces the universal app, ZIP, and checksum. Source and included derivative code use GPL-3.0-only.
